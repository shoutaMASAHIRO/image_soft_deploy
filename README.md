# 画像解析・秤量計算統合アプリケーション (Image Analysis & Weighing App)

このアプリケーションは、化学実験における秤量計算と、研究用画像の解析（コントラスト調整、寸法測定、粒子解析）をシームレスに行うための統合ツールです。

## 概要

Web技術（Python/Flask + JavaScript）をベースに構築されており、デスクトップアプリケーションとして単一の実行ファイル（`.exe`）形式で配布・実行が可能です。Python環境がインストールされていないPCでも、ダブルクリックするだけで自動的にブラウザが立ち上がり、直感的なUIで操作できます。

## 主要機能

### 1. 画像解析モジュール (JavaScript & Canvas API)
外部ライブラリに依存せず、ブラウザのCanvas APIを駆使して高速な画像処理を実現しています。

- **コントラスト調整**: シグモイド関数を用いたルックアップテーブル（LUT）によるリアルタイム調整。
- **鮮明化 (Sharpening)**: 3x3カーネルの畳み込み演算によるエッジ強調。
- **寸法測定**: スケール設定（px ↔ 実長）と、2点間距離の計測。
- **粒径解析 (Particle Analysis)**: 
  - グレースケール・2値化処理。
  - Flood Fillアルゴリズムによる粒子ラベリング。
  - 面積、周囲長、円相当径、円形度、アスペクト比の自動算出。
- **ROI選択・トリミング**: 特定領域の切り出しと、新しい元画像としての再定義。

### 2. 秤量計算モジュール
- **化学式パース**: 原子量データに基づき、入力された化学式からモル質量を自動計算。
- **秤量シミュレーション**: 生成物の目標量から必要な原料の必要量を算出。
- **履歴管理**: 計算結果をデータベースに保存し、インクリメンタルサーチで過去の履歴を呼び出し可能。

### 3. データ管理・永続化 (Flask & SQLAlchemy)
- **画像保存**: アップロードされた画像やROI抽出後の画像をデータベースに保存。
- **データベース**: ローカルではSQLite、クラウド環境（Render等）ではPostgreSQLを自動で切り替え。

## 技術スタック

### フロントエンド
- **言語**: JavaScript (ES6+), HTML5, CSS3
- **画像処理**: HTML5 Canvas API (Vanilla JS)
- **UI**: タブ切り替え、リアルタイムスライダー、モーダル UI

### バックエンド
- **言語**: Python 3.x
- **フレームワーク**: Flask
- **WSGIサーバー**: Waitress (安定稼働用)
- **ORM**: SQLAlchemy
- **画像処理(サーバー側)**: OpenCV (headless), Pillow
- **AI/DL (拡張用)**: PyTorch (DnCNN等のノイズ除去モデル統合用)

### 配布・パッケージング
- **PyInstaller**: Python環境一式、静的資産、ライブラリを単一の`.exe`に集約。
- **Docker**: コンテナ環境での実行にも対応 (`Dockerfile` 完備)。

## セットアップと実行

### 開発用起動
```bash
cd image-analysis-app
python app.py
```

### 実行ファイル化
`app.spec` ファイルを用いて PyInstaller でビルドします。
```bash
pyinstaller app.spec
```

## プロジェクト構造
- `app.py`: メインのFlaskサーバー・API定義。
- `static/js/script.js`: 画像処理、計算ロジック、UI制御の全コード。
- `static/css/style.css`: アプリケーションのデザイン定義。
- `templates/index.html`: メイン画面の構造。
- `技術スタック/`: 各種詳細仕様ドキュメント。
